# Single Arm Iso Row

## Details

- **Category:** Horizontal Pull
- **Difficulty:** intermediate
- **Movement pattern:** pull
- **Equipment:** Other
- **Primary muscles:** Upper Back, Lats
- **Secondary muscles:** Biceps

## Overview

A single-arm row with an isolateral machine that lets each side work independently.

## Instructions

1. Sit at the machine with your chest against the pad.
2. Hold one handle with a neutral grip.
3. Pull the handle toward your torso.
4. Squeeze your shoulder blade.
5. Return slowly.

## Cues

- Chest on the pad
- Pull to the ribs
- Slow return

## Common mistakes

- Twisting the torso
- Shrugging
- Using momentum

## Safety

Use a moderate load.

## Longevity notes

Pulling strength balances all the forward-reaching of daily life and protects the shoulders and upper back. A strong back is one of the best predictors of staying active and independent.
