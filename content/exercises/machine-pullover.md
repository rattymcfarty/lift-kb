# Machine Pullover

## Details

- **Category:** Vertical Pull
- **Difficulty:** beginner
- **Movement pattern:** pull
- **Equipment:** Machine
- **Primary muscles:** Lats
- **Secondary muscles:** Chest

## Overview

Machine Pullover is a beginner pulling exercise for the lats, performed with a machine. Pulling balances all the pressing we do in life and keeps the upper back and posture strong.

## Instructions

1. Adjust the seat so the machine's pivot aligns with your shoulders.
2. Grip the handles with elbows bent, pressed against the pads if provided.
3. Pull the handles down in an arc to your torso, squeezing the lats.
4. Return slowly to the stretched start — smooth motion, no jerking.

## Cues

- Chest up, shoulders down
- Pull the elbows to the ribs
- Squeeze at the top

## Longevity notes

Pull twice as much as you push and your posture will age well. Rowing and pull-up strength are among the best predictors of a capable, pain-free upper body later in life.
