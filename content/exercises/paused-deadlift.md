# Paused Deadlift

## Details

- **Category:** Hinge
- **Difficulty:** advanced
- **Movement pattern:** hinge
- **Equipment:** Barbell
- **Primary muscles:** Glutes
- **Secondary muscles:** Hamstrings, Lower Back, Lats

## Overview

Paused Deadlift is an advanced hip-hinge exercise targeting the glutes, performed with a barbell. The hinge is the foundation of safe lifting — it teaches you to load the hips, not the spine.

## Instructions

1. Set up for a conventional deadlift and pull the bar off the floor.
2. Pause for 1-2 seconds just below the knee, staying tight.
3. Finish the pull to full lockout.
4. Lower with control. The pause eliminates momentum and builds positional strength.

## Cues

- Hips back, spine long
- Feel the hamstrings load
- Squeeze glutes to finish

## Longevity notes

A strong hinge is back insurance. Learn it light, groove it often, and add load slowly — the goal is a back that never complains about picking things up.
