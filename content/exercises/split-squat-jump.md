# Split Squat Jump

A plyometric split squat that jumps and switches legs mid-air.

## Details

- **Category:** Cardio
- **Difficulty:** intermediate
- **Movement pattern:** cardio
- **Equipment:** Bodyweight
- **Primary muscles:** Quadriceps, Glutes
- **Secondary muscles:** Hamstrings, Adductors, Abs

## Instructions

1. Start in a split squat position.
2. Jump up explosively.
3. Switch legs mid-air.
4. Land softly in a split squat.
5. Repeat.

## Cues

- Land soft
- Chest tall
- Drive up

## Common mistakes

- Landing stiff
- Knee caving
- Leaning forward

## Safety

Skip with knee pain.
