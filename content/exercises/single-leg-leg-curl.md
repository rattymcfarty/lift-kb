# Single-Leg Leg Curl

## Details

- **Category:** Other
- **Difficulty:** intermediate
- **Movement pattern:** pull
- **Equipment:** Machine
- **Primary muscles:** Hamstrings

## Overview

A machine leg curl done one leg at a time.

## Instructions

1. Set up on the machine with the pad above one heel.
2. Curl your heel toward your glute.
3. Squeeze your hamstring.
4. Return slowly.
5. Switch legs.

## Cues

- Squeeze at the top
- Slow return
- Hips stay down

## Common mistakes

- Lifting the hips
- Using momentum
- Dropping the weight

## Safety

Use a moderate weight.

## Longevity notes

Pulling strength balances all the forward-reaching of daily life and protects the shoulders and upper back. A strong back is one of the best predictors of staying active and independent.
